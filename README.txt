# موقع المنصور - جلب المقطورات

## تشغيل الموقع
1. فك ضغط الملف.
2. افتح مجلد `al_mansour_website` في VS Code.
3. افتح `index.html` في المتصفح، أو شغّله باستخدام إضافة Live Server.

## الملفات
- `index.html`: هيكل الموقع ومحتواه.
- `style.css`: التصميم والألوان والتجاوب مع الموبايل.
- `script.js`: قائمة الموبايل ومعرض صور المنتج.
- `assets/`: صور المنتج الأصلية المرفوعة في المحادثة.
